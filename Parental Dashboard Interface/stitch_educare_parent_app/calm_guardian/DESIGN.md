# EduCare Parent App — Design System

## 1. Product Identity
Product name: EduCare
Platform: Mobile-first school management and transport application
Role: Parent
Core principle: "Tell me what is happening with my child."
Visual style: Calm, trustworthy, light, crisp, premium educational iOS/Android UI with clean rounded cards, soft drop shadows, and subtle pastel tint badges.

## 2. Color System
- Primary (EduCare Blue): #1769FF
- Primary Dark / Headings: #101B4B
- Primary Text: #101828
- Secondary Text: #667085
- Muted / Disabled: #98A2B3
- Background: #F7F9FC
- Surface / Card: #FFFFFF
- Border: #E4E7EC
- Divider: #EAECF0
- Success: #16A34A (Light tint: #ECFDF5)
- Warning: #F59E0B (Light tint: #FFFBEB)
- Error: #EF3340 (Light tint: #FEF2F2)
- Accent Purple (Results): #7C3AED (Light tint: #F5F3FF)
- Accent Orange (Announcements): #EA580C (Light tint: #FFF7ED)

## 3. Typography
Font family: Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
- Page Title: 24–28px, font-weight 700
- Section Heading: 18–20px, font-weight 600
- Card Heading: 16px, font-weight 600
- Body: 14–15px, font-weight 400
- Small / Caption: 12–13px, font-weight 500

## 4. Spacing & Elevation
- Spacing unit: 4px / 8px / 12px / 16px / 20px / 24px
- Border Radius: Cards 16px, Large Cards 20px, Buttons 12–14px, Badges / Pills 9999px
- Shadows: 0 2px 10px rgba(16, 24, 40, 0.06), elevated 0 4px 18px rgba(16, 24, 40, 0.08)
